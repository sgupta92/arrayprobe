# 1. Getting started

**What it is for.** Your first hour with the package: process one probe file, read what comes
out, pick an engine, and look at the particles behind a number.

**Who it is for.** Anyone new, including readers with no Python or probe-processing background.

**Order.** Read top to bottom.

1. `01_start_here`: one synthetic probe file in; particle images, a verdict on each, and a size distribution out.
2. `02_quickstart`: the same chain as five cells.
3. `03_choosing_an_engine`: the two shipped engines on one known-truth file, and which to use when.
4. `04_soda2_end_to_end`: the SODA-2 engine end to end on a known-truth flight.
5. `05_triage_and_gallery`: look at particles as a contact sheet and a gallery, and start the triage page to label them; no computed number changes.
6. `06_read_products`: open the output files directly and learn what each variable and the `.call` sidecar mean. The optional enhancements on the same kind of product follow in `7_analysis_and_outputs/08_enhancements_on_a_product`.
7. `07_working_with_an_ai_assistant`: the prompts to give an AI coding assistant: a first prompt, the questions it must ask you before processing, data your PI may already have processed, and safe practice.
8. `08_ai_assistant_with_your_own_data`: the prompts for an AI coding assistant when your data are already processed: examine the files, test a feature or option against them, check one data-quality aspect, and work with output file formats, keeping your files read-only.
9. `09_ai_assistant_limits_and_ethics`: responsibility, ethics and limits of using an AI assistant: who answers for a number, what data may not go into a prompt, the jobs not to hand it, the classes of mistake an assistant made while this package was built, and a checklist for any result it gives you.

**What you need.** Found by reading each notebook's code cells. All nine run from the
repository root (each starts with a guard that checks the working directory) and none needs a
file you supply.

| Notebook | Beyond the core package | Data |
|---|---|---|
| `01_start_here` | xarray, netCDF4, matplotlib | Demo flight generated in the notebook (`make_demo_flight`); shipped `tests/data` fixtures |
| `02_quickstart` | xarray, matplotlib | Demo flight generated in the notebook |
| `03_choosing_an_engine` | Runs the v3.5 and SODA-2 engines on the same data | Known-truth flight generated by `synthetic_truth`; reads the shipped `examples/configs/soda2/2ds_spec.toml` config |
| `04_soda2_end_to_end` | SODA-2 engine | Known-truth flight generated in the notebook; shipped config `examples/configs/soda2/2ds_spec.toml` |
| `05_triage_and_gallery` | Runs `arrayprobe gallery` as a subprocess; shows the `arrayprobe triage` command without starting it | Copies the shipped `tests/data/demo_flight_dense_raw.2DS` |
| `06_read_products` | None beyond the core package (`netCDF4`, `xarray`) | Demo flight generated; shipped synthetic fixtures `tests/data/v35_probetype1_sizedist/test_cip.sd.nc` and `tests/data/v35_sizedist/main.nc` |
| `07_working_with_an_ai_assistant` | None beyond the core package; runs `arrayprobe --help`, `tune settings`, `provenance --help` and `compare --help` as subprocesses | None; writes a question checklist into a temporary folder |
| `08_ai_assistant_with_your_own_data` | None beyond the core package; runs `arrayprobe provenance --help` and `compare --classes` as subprocesses | None; writes a question checklist and a prompt template into a temporary folder |
| `09_ai_assistant_limits_and_ethics` | numpy only | None; one cell recomputes a reported number from random data with a fixed seed |

Run from the repository root (`jupyter notebook examples/`).
